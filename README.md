# news-superagent-tech-ai

Superagent pipeline for top 5 Tech & AI trending news in USA, China, Europe, Venezuela.

## Output

* Daily summaries stored per day in `summaries/YYYY-MM-DD/`
* Each region has `top5_en.md` and `top5_es.md`
* Each item: ~150 words bilingual summary ready for talking avatar.

## Sources

* USA: TechCrunch, The Verge, Ars Technica, Wired
* China: 36Kr, 品玩, 澎湃新闻科技, IT之家
* Europe: The Register, Sifted, Wired UK, Tech.eu
* Venezuela: El Nacional, El Impulso, La Patilla, Prodavinci

## Usage

Run pipeline daily at 09:00 America/Caracas via superagent, or on-demand.
